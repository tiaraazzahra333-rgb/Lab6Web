Pengujian JavaScript tanpa defer

Halaman ini menguji apa yang terjadi ketika file JavaScript dijalankan dari bagian <head> tanpa atribut defer.

Catatan: Script sengaja dijalankan sebelum elemen tombol di bawah dibaca browser. Buka Developer Tools → Console untuk melihat nilai null dan pesan error.

Kesimpulan

Tanpa defer, browser menjalankan JavaScript ketika menemukan tag script di bagian head. Pada saat itu elemen body belum dibentuk, sehingga getElementById() menghasilkan null. Ketika addEventListener() dipanggil pada nilai null, terjadi error. Atribut defer menunda eksekusi script sampai HTML selesai diparsing.

Contoh perbaikan

<script src="script.js" defer></script>
