    Q&A

    Jawaban Pertanyaan Evaluasi

    Jawaban berdasarkan materi pada modul praktikum.

    1. Apa yang dimaksud dengan DOM dan apa manfaatnya?

      DOM (Document Object Model) adalah representasi struktur dokumen HTML dalam bentuk objek yang dapat diakses dan dimanipulasi oleh JavaScript. Manfaatnya yaitu memilih elemen, mengubah konten, mengatur kelas CSS, dan merespons tindakan pengguna.

    2. Apa perbedaan getElementById(), querySelector(), dan querySelectorAll()?

      getElementById() memilih elemen berdasarkan ID. querySelector() memilih elemen pertama yang cocok dengan selector CSS. querySelectorAll() memilih semua elemen yang cocok dengan selector CSS.

    3. Apa fungsi addEventListener() dan sebutkan tiga contoh event?

      addEventListener() menghubungkan suatu event dengan fungsi yang dijalankan ketika event terjadi. Contohnya click, input, dan submit.

    4. Mengapa event.preventDefault() digunakan pada event submit form?

      Untuk mencegah perilaku bawaan form, seperti halaman dimuat ulang, sehingga JavaScript dapat memeriksa data dan menampilkan hasil validasi terlebih dahulu.

    5. Apa perbedaan textContent dan innerHTML dari sisi penggunaan dan keamanan?

      textContent digunakan untuk menampilkan atau mengubah teks biasa. innerHTML digunakan untuk membaca atau mengubah markup HTML. textContent lebih aman untuk menampilkan input pengguna karena tidak menafsirkan teks sebagai HTML.

    6. Bagaimana classList.toggle() membantu mengubah tampilan elemen?

      classList.toggle() menambahkan kelas jika kelas belum ada dan menghapusnya jika sudah ada. Dengan demikian, tampilan elemen dapat diaktifkan atau dinonaktifkan melalui JavaScript.

    7. Sebutkan minimal tiga skenario pengujian validasi form.

      Semua input dikosongkan, format email tidak valid, usia di bawah 17 tahun, nama kurang dari tiga karakter, serta seluruh input diisi dengan benar.
